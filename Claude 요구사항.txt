7. 국체 3년 금리 (1주 단위, 오늘로부터 3년치 데이터)

가능하면 한국 시간 저녁 6시에 모든 데이터를 하루단위로 추가(혹은 업데이트 미국채는 주간단위라서.)
수집을 위해서는 한국투자증권 오픈 API를 활용하도록 함.
종목 정보는 아래 링크에서 확인.
https://apiportal.koreainvestment.com/apiservice-category
로컬에 종목 정보를 저장할 때는 별도 디렉토리를 생성한 뒤 따로 저장
API 정보는 아래 링크에서 확인.
https://apiportal.koreainvestment.com/apiservice-apiservice
API를 확인하고 코드를 작성할 때는 "kis-code-assistant-mcp"를 아주 적극적으로 활용하여 토큰 사용을 최대한 줄일 것.


모든 데이터는 구글 시트에 정리
1. 최초 정리는 API등을 활용하기 않고 로컬에서 만든뒤 업로드 하는 방식으로 하면 좋을 듯함 (API 사용량 최적화)
2. 이후 일간으로 업데이트 하는 것은 루틴하게 동작하면 API를 통해 추가
3. 추가하는 작업은 Claude에서 수행할 예정이므로 루틴한 작업을 설정할 수 있도록 가이드 제공 필요

정리된 데이터를 한눈에 확인할 수 있는 대시보드와 같은 시트가 필요.
1. 데이터가 정리된 파일과 같은 구글 시트에 별도 시트에 각각의 정보를 캔들로 시각화 한 차트가 여러개 있는 시트를 별도로 구성
2. 직접 구성하는데 많은 토큰 사용이 예상된다면 직접 구성할 수 있는 가이드 제공.

위 모든 수집과정과 엑셀 데이터를 만들어내는 과정은 로컬에 코드를 작성하여 로컬에서 수행하도록 함.

구글 시트에 정리하는 작업은 일단 다음 단계에서 진행하고, 이번 단계에서는 위 지표들을 수집하는 python 프로그램과 수집한 데이터를 구글시트에 옮기기 위한 최초 파일을 생성해줘.
